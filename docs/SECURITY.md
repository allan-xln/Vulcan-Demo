# Segurança

Esta demo é estática e não usa backend real.

## O Que Não Existe Aqui

- chave OpenAI;
- chave Supabase;
- service role;
- senha de banco;
- token WhatsApp;
- credencial SMTP;
- dados reais de clientes.

## Arquivos Protegidos Por `.gitignore`

- `.env`;
- `.env.*`;
- certificados e chaves;
- bancos locais;
- builds e logs.

## Dados

Todos os dados são simulados e ficam em `data/demo.ts`.
